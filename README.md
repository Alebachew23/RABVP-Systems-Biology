# RABV-P Systems Biology
This repository holds scripts used to analyze RNAseq and transcription factor prediction data and generate all figures for the manuscript entitled “Rabies virus interferon antagonist P protein selectively modulates interferon signalling to inhibit antiviral genes while supporting proviral gene expression”. 

This project is set up for an RStudio workflow with a project root anchored by `Analysis_Code.Rproj`.

## Project structure

- `scripts/` - supporting R scripts
- `R/` - reusable R functions or source files
- `data_raw/` - raw input data
- `data_processed/` - cleaned or intermediate data used by the analysis
- `results/figures/` - figures generated by the analysis
- `results/tables/` - tables and exported summary files
- `Analysis_Code.Rmd` - main analysis document

## How to run the analysis

1. Open `Analysis_Code.Rproj` in RStudio.
2. Make sure the input data files expected by `Analysis_Code.Rmd` are placed in `data_raw/` and `data_processed/` using the same folder names referenced in the script.
3. Install the R packages used by the analysis if they are not already available.
4. Knit `Analysis_Code.Rmd` or run its chunks from top to bottom.

## Notes

- The analysis script uses `here::here()` so paths resolve from the project root.
- Output files are written under `results/figures/` and `results/tables/`.
